# Scriptureborn - Вертикальный слайс

2D игра с видом сверху (Top-Down) на Godot Engine 4.x. Основная фишка — физика движения и крюк-кошка с реалистичной веревкой.

## 📁 Структура проекта

```
Scriptureborn/
├── project.godot                    # Конфигурация проекта
├── icon.svg                         # Иконка проекта
├── scenes/
│   ├── Main.tscn                   # Главная сцена с ареной
│   ├── Player.tscn                 # Сцена игрока с крюком
│   └── Projectile.tscn             # Сцена снаряда
├── scripts/
│   ├── Player.gd                   # Контроллер игрока (166 строк)
│   ├── GrapplingHook.gd            # Система крюка-кошки (293 строки)
│   ├── Projectile.gd               # Логика снаряда (191 строка)
│   ├── ProjectileManager.gd        # Менеджер снарядов (154 строки)
│   └── Main.gd                     # Главная сцена (163 строки)
├── assets/
│   └── procedural_player_shader.gdshader
└── docs/
    ├── README.md                    # Этот файл
    └── scene_structure.md           # Детальная структура сцены
```

## 🔧 Настройка физики (Physics Layers)

В проекте настроены следующие слои коллизий:

| Layer | Name | Description |
|-------|------|-------------|
| 1 | Player | Игрок и его коллизии |
| 2 | Walls | Стены и препятствия |
| 3 | Hook | Сегменты веревки крюка |
| 4 | Projectile/HookHead | Снаряды и голова крюка |

### Collision Matrix

```
Player (1):      mask = 2 (Walls)
Walls (2):       mask = 7 (Player + Walls + Hook)
Hook (3):        mask = 2 (Walls)
Projectile (4):  mask = 2 (Walls)
HookHead (4):    mask = 2 (Walls)
```

## 🚀 Запуск проекта

1. Откройте Godot Engine 4.2 или новее
2. Нажмите "Import" и выберите файл `project.godot`
3. Откройте сцену `scenes/Main.tscn`
4. Нажмите F5 для запуска

## 📋 Компоненты

### Player.gd
- Движение с ускорением и трением
- Поворот к курсору мыши (`look_at()`)
- Интеграция с крюком и оружием через сигналы
- Состояния: IDLE, MOVING, GRAPPLED

### GrapplingHook.gd
**Состояния крюка:**
- `IDLE` - неактивен
- `FIRING` - полёт к цели
- `ATTACHED` - закреплён на стене
- `RETRACTING` - возврат к игроку

**Физика веревки:**
- 8 сегментов RigidBody2D
- DampedSpringJoint2D для соединений
- stiffness=40, damping=5 для плавности
- Line2D для визуализации
- Защита от джиттера через damping настройки

### Projectile.gd
**Состояния снаряда:**
- `FLYING` - полёт вперёд
- `RETURNING` - возврат как бумеранг
- `HIT` - попадание в цель

**Уникальная механика:**
- После 1.5 сек полёта разворачивается
- Возвращается к игроку
- Восстанавливает ресурс при возврате

### ProjectileManager.gd
- Пул объектов (max 20 снарядов)
- Оптимизация создания/удаления
- Обработка сигналов попадания

## 🛠️ Технические детали

### Требования
- Godot Engine 4.2+
- Совместимость с будущими версиями 4.6+

### Особенности кода
- Строгая типизация GDScript (`var speed: float = 300.0`)
- Отсутствие предупреждений компилятора
- Сигналы для связи между компонентами
- Комментарии на русском языке

### Производительность
- Пулинг снарядов для избежания аллокаций
- Оптимизированная физика веревки
- Line2D для эффективной отрисовки
