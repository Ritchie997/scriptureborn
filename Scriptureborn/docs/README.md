# Scriptureborn - Инструкция по настройке и запуску

## Требования
- Godot Engine 4.2 или выше (рекомендуется 4.6+)
- ОС: Windows 10/11, macOS 10.15+, или Linux

## Структура проекта

```
Scriptureborn/
├── project.godot              # Конфигурация проекта Godot
├── scenes/                    # Файлы сцен (.tscn)
│   ├── Main.tscn             # Главная сцена игры
│   ├── Player.tscn           # Сцена игрока
│   └── Projectile.tscn       # Сцена снаряда
├── scripts/                   # GDScript скрипты
│   ├── Main.gd               # Логика главной сцены
│   ├── Player.gd             # Контроллер игрока
│   ├── GrapplingHook.gd      # Система крюка-кошки
│   ├── Projectile.gd         # Логика снаряда
│   └── ProjectileManager.gd  # Менеджер снарядов
├── assets/                    # Ресурсы (шейдеры, текстуры)
│   └── procedural_player_shader.gdshader
└── docs/                      # Документация
    └── scene_structure.md    # Описание структуры сцены
```

## Установка и запуск

### Шаг 1: Открытие проекта
1. Запустите Godot Engine 4.x
2. Нажмите "Import" (Импорт)
3. Выберите файл `project.godot` из папки проекта
4. Проект появится в списке, нажмите на него для открытия

### Шаг 2: Настройка Input Map (уже настроено в project.godot)
Проект уже содержит следующие настройки управления:
- **Left Mouse Button** → `left_click` (крюк)
- **Right Mouse Button** → `right_click` (выстрел)
- **WASD** → стандартные действия Godot (`ui_up`, `ui_down`, `ui_left`, `ui_right`)
- **Space** → `ui_space` (отцепка крюка)

Если нужно проверить или изменить:
1. Project → Project Settings → Input Map
2. Убедитесь, что действия настроены корректно

### Шаг 3: Настройка Physics Layers (уже настроено)
Физические слои настроены в project.godot:
- **Layer 1**: Player
- **Layer 2**: Walls/Obstacles
- **Layer 3**: Grappling Hook
- **Layer 4**: Projectiles

Проверка:
1. Project → Project Settings → Layer Names → 2D Physics
2. Убедитесь, что слои названы корректно

### Шаг 4: Запуск игры
1. Откройте сцену `scenes/Main.tscn` (двойной клик)
2. Нажмите F5 или кнопку Play вверху справа
3. Игра запустится в окне 1920x1080

## Управление в игре

| Действие | Кнопка | Описание |
|----------|--------|----------|
| Перемещение | W, A, S, D | Движение игрока |
| Прицеливание | Мышь | Игрок поворачивается к курсору |
| Крюк-кошка | ЛКМ | Бросок крюка в сторону курсора |
| Выстрел | ПКМ | Запуск снаряда |
| Отцепка | Пробел или ЛКМ (повторно) | Отмена притяжения крюка |

## Параметры настройки (в инспекторе Godot)

### Player.gd
- **Speed**: Скорость перемещения (по умолчанию 300)
- **Acceleration**: Ускорение (по умолчанию 15)
- **Friction**: Торможение (по умолчанию 20)

### GrapplingHook.gd
- **Hook Speed**: Скорость полета крюка (по умолчанию 800)
- **Max Hook Distance**: Максимальная дальность (по умолчанию 600)
- **Segment Count**: Количество сегментов веревки (по умолчанию 8)
- **Spring Stiffness**: Жесткость пружины (по умолчанию 40)
- **Spring Damping**: Затухание колебаний (по умолчанию 5)

### Projectile.gd
- **Speed**: Скорость полета (по умолчанию 600)
- **Return Speed**: Скорость возврата (по умолчанию 800)
- **Max Flight Time**: Время до возврата (по умолчанию 1.5 сек)
- **Damage**: Урон (по умолчанию 25)

### Main.gd
- **Arena Size**: Размер арены (по умолчанию 1000x1000)
- **Wall Thickness**: Толщина стен (по умолчанию 50)
- **Obstacle Count**: Количество препятствий (по умолчанию 5)

## Решение проблем

### Предупреждения в консоли
Если видите предупреждения о неиспользуемых переменных:
- Это нормально для демо-версии
- Некоторые методы подготовлены для будущего расширения

### Дрожание веревки (Jitter)
Если веревка дрожит:
1. Увеличьте `Spring Damping` в GrapplingHook.gd
2. Уменьшите `Spring Stiffness`
3. Проверьте FPS (должен быть стабильным)

### Крюк не цепляется
Проверьте:
1. Collision Layer у крюка = 3
2. Collision Mask у крюка = 2
3. Стены имеют Layer = 2

### Снаряды не возвращаются
Проверьте:
1. `Max Flight Time` > 0
2. Игрок существует в сцене
3. Ссылка на player_reference установлена

## Расширение функционала

### Добавление врагов
1. Создайте новую сцену с Area2D
2. Добавьте в группу "enemies"
3. Снаряд будет наносить урон при столкновении

### Новые типы крюков
Наследуйте от GrapplingHook.gd и измените:
- Параметры физики
- Поведение при зацепе
- Визуальные эффекты

### Система ресурсов
Добавьте в Player.gd:
```gdscript
@export var max_resource: float = 100.0
@export var current_resource: float = 100.0
```
